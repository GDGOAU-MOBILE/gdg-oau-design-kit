# Agent instructions

This repository is the GDGOAU design kit. If you are an AI agent working on anything for GDG on Campus OAU
(slides, PDFs, websites, social posts, event materials), read `SKILL.md` first and follow it exactly. It
links to everything else: brand rules, components, writing rules (including the vendored humanizer), the
intake questions, the partner's-eye review and the templates.

Do not skip the intake questions in `references/questions.md`, and do not deliver without running
`references/review.md`.
